# Support

Need help or have a question?

- **Questions and ideas** - open a discussion or an issue.
- **Something broken?** - open an issue with which platform, which hook and what happened. See
  [guides/checks.md](guides/checks.md) first, the behaviour might be intentional.
- **Adding your own rules** - see [guides/extending.md](guides/extending.md) before opening an
  issue asking for a new personal-style check to be added upstream.

> [!IMPORTANT]
> For a security issue, follow [SECURITY.md](SECURITY.md) rather than posting publicly.
