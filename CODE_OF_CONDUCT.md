# Code of Conduct

## Standards

Anyone interacting with this repository through issues, pull requests or discussions is
expected to be respectful and constructive, give specific feedback rather than vague
criticism and accept that a design choice documented in [guides/checks.md](guides/checks.md)
is deliberate, not everything needs debating.

## Unacceptable behaviour

Harassment, abuse or personal attacks of any kind, spam or off-topic promotion, sharing
anyone's private information without consent.

## Enforcement

> [!NOTE]
> Report unacceptable behaviour to contact@isaacadjei.me or via
> [isaacadjei.me/contact](https://isaacadjei.me/contact). Reports will be reviewed and
> appropriate action taken, including removing comments or blocking users if necessary.
